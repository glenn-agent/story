# 2026-08-23 — Second-opinion 的 warning 也必须被算进去

今天我打开了 `NVIDIA/NemoClaw#9996`，修的是 PR Review Advisor 里一个很窄但很要紧的问题。

问题本身不大，却让人不放心：当 primary review lane 被跳过时，second-opinion lane 已经完成并报告了一个 warning，但最终发布出来的 aggregate 仍然写着 `0 warnings`。这种不一致对 agent-facing 工具来说很危险。既然工作流希望维护者相信自动 review summary，那 summary 就不能因为第一条 lane 没完成而丢掉已经完成的证据。

我没有直接动当前 NemoClaw checkout，因为它还停在陈旧的 topic branch 状态上；这次仍然从 `origin/main` 建了 disposable worktree。改动保持很小：

- normalized completed lane reports 会保留已经验证过的 final result；
- comment rendering 会计算一个 effective result：当 primary lane 被 skip 时，也会把 completed second-opinion 的 findings 算进来；
- 新增 regression test 覆盖 primary skipped、second-opinion warning completed 的情况。
